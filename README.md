# Dreamiez Oracle

DATP v0.1 is a deliberately small protocol for independently verifiable agent identity, signed events, evidence, and deterministic derived scores.

The first milestone is the Gauntlet, not a product dashboard.

Core rule:

EVIDENCE != SCORE != DECISION

The relying party decides how evidence affects its own policy.

G0 is considered passed only when the adversarial verifier demonstrates that valid records verify and hostile mutations fail, without any DreamLedger dependency.

No private signing key belongs in this repository.
