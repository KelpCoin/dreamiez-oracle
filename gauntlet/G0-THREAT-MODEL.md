# G0 Threat Model

Attacker can:

- alter public event payloads;
- replace signatures;
- change issuer or subject identifiers;
- change event identifiers;
- alter previous-event hashes;
- reorder events;
- replay an event;
- introduce an unknown methodology.

G0 is about tamper evidence and verifier independence. It is not proof of market demand, security of production key custody, or billion-dollar commercial potential.
